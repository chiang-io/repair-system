# 貨櫃裝箱模擬

單頁網頁工具：選擇櫃型、填寫貨物清單，計算擺放位置並以 3D 逐件播放裝載順序。

網址：https://iop15159.github.io/repair-system/

## 功能

- 櫃型：20GP／40GP／40HQ，依公司貨櫃規格表：內徑 590×235×239、1203×235×238、1203×235×269 cm，最大載重 20／24／25 噸；可在頁面上自己改。
- 貨物清單：品名、長寬高（cm）、單重（kg）、件數，以及「直立」（只能水平旋轉）與「可堆疊」（取消後上方不再放貨）限制。
- 以極點（extreme point）啟發式計算擺放位置；懸空貨物需有 70% 以上底面由可堆疊貨物支撐。比較 6 種擺放策略，取裝載體積最大者。
- 結果：已裝件數、容積利用率、載重、重心偏移（超過櫃長 ±10%／±20% 時警示）、各品項未裝件數、每件貨物的位置與擺放尺寸。
- 「放地板」：勾選的貨物只放在地板上（不疊在別的貨上面），並優先裝入。
- 「位置」：每種貨物可指定放在最裡面、中間或靠門口，用來調整配重；「自動」由系統決定。
- 間隙：只有前後間隙（排與排之間，預設 10 cm）；左右只看塞不塞得進去，上下不留間隙。
- 排法：預設「同品項一排一排」（照現場習慣，重的品項先排在最裡面，每排左右置中，排不下的再補空位），可改「系統自動找最滿」。
- 堆高機規則：捆的長度放得進櫃寬就一律橫放（堆高機直接推進去）；放不進的才順著貨櫃長邊放。
- 重的不壓在輕的上面（預設勾選；桿件很耐壓，上面放棧板或其他貨都可以）；桿件類（TB、主架、平主架、橫桿、斜桿、蜂巢鋼、基座、輔助桿）一律平放。
- 「裝完再勾：平均分開」：把貨物分成前後幾段，多出來的長度平均分到每段之間，第一段貼最裡面、最後一段貼門口（預設不勾，排的時候先照間隙靠最裡面排）。
- 手動調整：在 3D 點一捆貨物，畫面下方出現控制列，可往裡、往門口、往左、往右、轉向；位置用「第幾排・左/中/右・第幾層」表示。移動後所有貨物自動往下落補位；推到牆就停。可「復原上一步」或「回到原本的排法」。進階可顯示公分位置直接輸入。重疊、懸空、壓在不可堆疊或較輕的貨物上會標紅。
- 這張單要幾櫃：三種櫃型各要幾櫃並建議櫃數最少的；一櫃裝不下時顯示還差幾件、多少 kg，可切換看每一櫃怎麼排（自動分櫃）。
- 混綁：按「混綁一捆…」列出可以一起綁的長度，直接填各長度支數（主架＋平主架、橫桿＋斜桿、輔助桿 0.25＋0.5、Top Beam 不同長度；不超過原本一捆的支數，長度取最長）。
- 常用品項：先選品項，再點尺寸按鈕（只有一種尺寸的直接選好）。
- 3D 視角：點貨物時視角移到那件、右鍵（手機兩指）平移、雙擊空白處回原本視角。
- 長桿件：比櫃寬長、只能順著長邊放的貨（要用吊的），長短貨混裝時位置自動放靠門口；整櫃都是長貨就從最裡面排。
- 同品項一排一排：別的桿件會先疊到已排好的排上面（例如不同長度的斜桿、橫桿疊在同一排），疊不上去才開新的一排。
- 手把：點 3D 貨物後出現左上角的小控制框（可按「－」收起來）：方向鍵（裡／門口／左／右）、上一層／下一層、轉向、復原；推到別捆旁邊會自動疊上去。鍵盤像玩遊戲：方向鍵移動、W／S 上下層、R 轉向、Z 復原、Tab 換下一件、Esc 不選。
- 裝不下提示：結果上方紅框列出哪些品項、各幾件沒裝，以及原因（重量超過或空間不夠）；貨物清單「已裝」欄顯示每種貨裝了幾件。
- 給現場的裝櫃圖：從上面往下看、從側面看，標第幾件與疊幾層；「每一排放什麼」清單可一鍵複製貼到 LINE。
- 手機版：貨物清單在手機上變成一張張卡片，不用左右滑。
- 常用品項：下拉選單選 Top Beam、主架、平主架、橫桿、斜桿、蜂巢鋼、基座、輔助桿、U 調（170 支/板）、下調（250 支/板）、橫桿 0.6m（400 支/板）、棧板或木箱（重型為主），填單子上的「總共幾支」（或直接填捆數），系統即時拆成「幾捆＋零頭幾支」；「每捆幾支」預設照品項、可改（例如蜂巢鋼 30 或 40 支一捆，一捆高度照層數重算）。同一類產品的零頭（不同長度也可以）合成一捆，不超過原本一捆的支數。包裝規格整理自歷年裝櫃明細，單重取自存貨表。
- 最多疊：每種貨物可設定同一疊最多疊幾層（橫桿預設 3 層），自動排不會超過，手動調整超過會標紅。
- 上方數字：已裝件數、容積利用率、載重、還能裝多少 kg（重量先滿會提醒）、門口剩餘長度、重心位置。
- 存檔：貨物清單、櫃型、間隙與手動調整的位置可存在瀏覽器，下次讀取；櫃型的內尺寸與最大載重可自己改。
- 外觀：棧板（木棧板加包膜、標示長寬高）、Top Beam（接近長方形、底面窄開口的斷面，4 支寬小捆，80 支兩小捆合成一大捆）、主架／平主架（一支一支畫：照實際支數、每 50 cm 一個圓盤、主架連接棒同一邊、橘色貼紙；混綁長的在下）、基座／輔助桿（短管頭尾接著排，每支 = 粗套管＋一個圓盤＋細管，輔助桿有黃色貼紙）、斜桿（每支畫出：鍍鋅管、兩頭壓扁接斜桿頭、橘色＋尺寸顏色貼紙：黃 0.6×1.5、藍 0.9×1.5、淺藍 0.9×1.0、紫 1.2×1.5、紅 1.5×1.5、綠 1.8×1.5、粉紅 2.4×1.5）、橫桿（每支畫出，鍍鋅管、橘色標籤、橫桿頭與楔子、上下層錯開）。3D 中標示「最裡面」，右上角可回到原本視角。
- 打開頁面時是空的 40HQ 櫃，要看範例再按「載入範例」。
- 最上面大結果：頁面頂端一直顯示要幾櫃（例如「40HQ × 1＋20GP × 1」）、件數重量，有更省的櫃型會寫「建議：改用…」。
- 分櫃：最後一櫃剩下的貨小櫃裝得下就用小櫃（先試 20GP 再 40GP）；可勾「平均分到每一櫃」讓每櫃一樣滿；控制框的「→ 移到第 N 櫃」可以把一捆搬到別櫃（自動找空位）。
- 貨物清單：品名 → 件數 → 已裝 → 長寬高 → 每件重；保持平放、可堆疊、放地板、最多疊、位置收起來，勾「顯示更多欄位」才出現。排法設定（間隙、排法、重的不壓輕的、平均分開）收在清單下面。
- 外觀：U 調（螺桿＋U 型頭）、下調（螺桿＋圓角薄底板）、橫桿 0.6m 板（2×2 小捆）畫成棧板上的產品，一般棧板仍是示意。
- 實際單重（選填）：過磅後可填每個常用品項的實際 kg/支，存在瀏覽器，之後加入都照這個算；空白照資料單重。
- 範例：橫桿 1.8m 十捆（20 呎櫃）、訂單 1150423007 第 1 櫃（40HQ）照片的實際裝法與系統自動排、主架＋橫桿＋斜桿一櫃、Top Beam 一櫃、一般紙箱。
- 3D 檢視使用 jsDelivr 的 three.js 0.128.0，可拖曳旋轉並逐件播放；CDN 載入失敗時仍可查看裝載順序表。

## 限制

- 結果為快速近似解，不保證最佳。
- 未處理地板承重、分批卸貨順序與多櫃分配。
- 「一般紙箱」範例為虛構資料；Top Beam 範例的包裝尺寸取自公司歷年裝櫃明細。

## 開發

純靜態網頁，沒有建置步驟。本機預覽：

```bash
python3 -m http.server 8000
```

再開啟 http://localhost:8000/ 。

## 庫存查詢（`inventory/`）

- 手機查詢：https://iop15159.github.io/repair-system/inventory/
- 電腦上傳：https://iop15159.github.io/repair-system/inventory/upload.html

給倉管在現場用手機查庫存。電腦上傳 ERP 的「存貨異動統計表-分倉」，大家的手機自動同步；不需要 Claude 或任何付費服務。

### 更新資料（電腦）

1. 打開上傳頁，選 PDF（或 Excel）。頁面會列出各倉品項數與結存合計，可和報表的「合計」比對。
2. 輸入公司密碼（電腦會記住），按「下載資料檔」，得到加密的 `inventory-data.json`。
3. 到 GitHub 的 `inventory/` 資料夾上傳頁（Add file → Upload files），把檔案拖進去，按 Commit changes。檔名必須是 `inventory-data.json`。
4. 約 1～2 分鐘後 GitHub Pages 更新，手機打開或切回頁面時會自動抓新資料。

### 說明

- 這個倉庫是公開的，所以資料檔用公司密碼加密（PBKDF2-SHA256 20 萬次 + AES-256-GCM）；檔案裡只有日期與筆數是明碼。手機第一次要輸入密碼，之後記住。換密碼時，手機會先顯示舊資料並要求輸入新密碼。
- 不要把原始報表（PDF、Excel）放進這個倉庫，只放加密後的 `inventory-data.json`。
- 讀檔：PDF 依文字位置拆出產品編號、品名規格、結存數量、單重；Excel 依標題列（產品編號、品名、結存數量、單重、倉別）找欄位。程式在 `inventory/common.js`。
- 查詢：預設只看 02 新品倉、06 五金倉，可切換其他倉；同一編號在不同倉的數量合在一張卡片；不分大小寫與全形半形，可打多段（例如「斜桿 1.8」）。資料超過 7 天提醒；負數庫存標紅。
- 備料清單：加入品項、填要備的數量、勾選已備好，可複製貼到 LINE（只存在各自的手機）。
- 離線：`inventory/sw.js` 快取頁面；資料解密後存在手機，沒有網路也能查。讀檔工具（jsDelivr 的 pdfjs-dist 3.11.174、xlsx 0.18.5）只有電腦上傳時才會下載。

## 檔案

- `index.html`：貨櫃裝箱模擬頁面。
- `icons/`、`manifest.webmanifest`：手機「加入主畫面」使用的圖示與名稱（貨櫃裝箱）。
- `container-loading/index.html`：舊網址，自動轉到首頁。
- `inventory/`：庫存查詢。`index.html` 手機查詢、`upload.html` 電腦上傳、`common.js` 讀檔與加密、`sw.js` 離線、`inventory-data.json` 加密後的資料（由上傳產生，不要手動編輯）。
- `sw.js`：清除舊版報修系統的離線快取並解除註冊，請勿刪除，直到確定沒有舊使用者。

舊版報修登記系統的檔案已移除，可從 Git 歷史（commit `9d23908` 之前）找回。
