# 貨櫃裝箱模擬

單頁網頁工具：選擇櫃型、填寫貨物清單，計算擺放位置並以 3D 逐件播放裝載順序。

網址：https://iop15159.github.io/repair-system/

## 功能

- 櫃型：20GP／40GP／40HQ，顯示內尺寸、容積、最大載重與 ISO 尺寸代碼。
- 貨物清單：品名、長寬高（cm）、單重（kg）、件數，以及「直立」（只能水平旋轉）與「可堆疊」（取消後上方不再放貨）限制。
- 以極點（extreme point）啟發式計算擺放位置；懸空貨物需有 70% 以上底面由可堆疊貨物支撐。比較 6 種擺放策略，取裝載體積最大者。
- 結果：已裝件數、容積利用率、載重、重心偏移（超過櫃長 ±10%／±20% 時警示）、各品項未裝件數、每件貨物的位置與擺放尺寸。
- 「放地板」：勾選的貨物只放在地板上（不疊在別的貨上面），並優先裝入。
- 「位置」：每種貨物可指定放在最裡面、中間或靠門口，用來調整配重；「自動」由系統決定。
- 間隙：前後間隙（預設 10 cm）與左右間隙（預設 5 cm）分開設定，只留在貨物和貨物之間，靠牆那面不留；上下不留間隙。
- 「裝完再勾：平均分開」：把貨物分成前後幾段，多出來的長度平均分到每段之間，第一段貼最裡面、最後一段貼門口（預設不勾，排的時候先照間隙靠最裡面排）。
- 手動調整：裝貨順序表可直接改每件的 x（離最裡面）、y（離左邊）、z（離地板）或水平旋轉；重心即時重算，超出貨櫃、重疊、懸空、壓在不可堆疊貨物上會標紅。按「計算裝箱」會重新自動排列。
- 常用品項：下拉選單選 Top Beam、主架、平主架、橫桿、斜桿或棧板（重型為主），輸入「整捆數＋零頭支數」加入清單。同一類產品的零頭（不同長度也可以）合成一捆，不超過原本一捆的支數。包裝規格整理自歷年裝櫃明細，單重取自存貨表。
- 最多疊：每種貨物可設定同一疊最多疊幾層（橫桿預設 3 層），自動排不會超過，手動調整超過會標紅。
- 上方數字：已裝件數、容積利用率、載重、還能裝多少 kg（重量先滿會提醒）、門口剩餘長度、重心位置。
- 存檔：貨物清單、櫃型、間隙與手動調整的位置可存在瀏覽器，下次讀取；櫃型的內尺寸與最大載重可自己改。
- 外觀：棧板（木棧板加包膜、標示長寬高）、Top Beam（長方形斷面，4 支寬小捆，80 支兩小捆合成一大捆）、主架／平主架（10 × 10 圓管、每 50 cm 圓盤、木板加鋼帶）、斜桿（深灰管、兩頭包膜）、橫桿（每支畫出，鍍鋅管、橘色標籤、橫桿頭與楔子、上下層錯開）。3D 中標示「最裡面」，右上角可回到原本視角。
- 範例：橫桿 1.8m 十捆（20 呎櫃）、訂單 1150423007 第 1 櫃（40HQ）照片的實際裝法與系統自動排、主架＋橫桿＋斜桿一櫃、Top Beam 一櫃、一般紙箱。
- 3D 檢視使用 jsDelivr 的 three.js 0.128.0，可拖曳旋轉並逐件播放；CDN 載入失敗時仍可查看裝載順序表。

## 限制

- 結果為快速近似解，不保證最佳。
- 未處理地板承重、分批卸貨順序與多櫃分配。
- 「一般紙箱」範例為虛構資料；Top Beam 範例的包裝尺寸取自公司歷年裝櫃明細。

## 開發

純靜態網頁，沒有建置步驟。本機預覽：

```bash
python3 -m http.server 8000
```

再開啟 http://localhost:8000/ 。

## 檔案

- `index.html`：貨櫃裝箱模擬頁面。
- `icons/`、`manifest.webmanifest`：手機「加入主畫面」使用的圖示與名稱（貨櫃裝箱）。
- `container-loading/index.html`：舊網址，自動轉到首頁。
- `sw.js`：清除舊版報修系統的離線快取並解除註冊，請勿刪除，直到確定沒有舊使用者。

舊版報修登記系統的檔案已移除，可從 Git 歷史（commit `9d23908` 之前）找回。
