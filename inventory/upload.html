上傳庫存（電腦用）

網站上的資料：檢查中…

把 ERP 的「存貨異動統計表-分倉」上傳到網站，大家的手機打開「庫存查詢」就會自動更新。整個過程大約 1 分鐘。

1選擇報表

把 PDF 或 Excel 拖到這裡，或

2公司密碼

資料會用這組密碼加密，因為網站是公開的。手機第一次打開時要輸入同一組密碼。這台電腦會記住。

3下載資料檔

按下面的按鈕，會下載一個 inventory-data.json（已加密）。

4放到 GitHub

  1. 按 打開 GitHub 上傳頁面（要先登入 GitHub）。
  2. 把剛剛下載的 inventory-data.json 拖進去。
    檔名一定要是 inventory-data.json；如果下載時變成 inventory-data (1).json，請先改回來。
  3. 拉到最下面，按綠色的 Commit changes。
